M02 — Onboard
ช่างหยุดกลางคันเพราะฟอร์มยาวเกิน
แก้: ใช้ Step-by-step (3 ขั้นตอน) + Pre-fill จาก Data ที่มี
M02 — Onboard
App Crash ระหว่าง Upload รูปโปรไฟล์
แก้: Compress ก่อน Upload + Retry Logic + Progress Bar
M03 — Build
Data ไม่ sync ระหว่าง Booking System กับ Profile
แก้: Event-driven Sync + Manual Refresh Button + Error State
M05 — Campaign
ช่างไม่เข้าใจ Condition ของ Campaign
แก้: Plain Language Condition + FAQ + Example "นับงานประเภทไหนบ้าง"
M07 — Financial
เอกสารไม่ถูก Format ที่ธนาคารต้องการ
แก้: ประสาน Legal + ธนาคารล่วงหน้า ทำ Template ที่ผ่าน Acceptance Test
